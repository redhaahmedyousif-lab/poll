# Community Health Habits in Bahrain 🇧🇭
### العادات الصحية في مجتمع البحرين

**IB MYP Design Project · مشروع تصميم – برنامج السنوات المتوسطة**

## Project Overview

Many people in Bahrain walk too little, drink too little water and spend long hours on screens, especially in the hot summer months. This project aims to design a simple digital health tracker that helps students, teachers and community members build better daily habits.

This web survey is the **research stage (Criterion A: Inquiring & Analysing)** of the MYP Design Cycle. It collects data on the community's current habits and tests two design hypotheses about the app's interface.

## لمحة عن المشروع

يعاني كثير من أفراد المجتمع في البحرين من قلة المشي وقلة شرب الماء وطول الجلوس أمام الشاشات، خاصة في أشهر الصيف الحارة. يهدف هذا المشروع إلى تصميم تطبيق رقمي بسيط لمتابعة العادات الصحية يساعد الطلاب والمعلمين وأفراد المجتمع على بناء عادات يومية أفضل.

يمثّل هذا الاستبيان مرحلة **البحث والتحليل (المعيار A)** في دورة التصميم، حيث يجمع بيانات عن العادات الحالية في المجتمع ويختبر فرضيتين حول تصميم واجهة التطبيق.

## Research Questions · أسئلة البحث

| Step | Question | السؤال |
|---|---|---|
| 1 | Role in the community | الدور في المجتمع |
| 2 | Daily steps | عدد الخطوات اليومية |
| 2 | Daily water intake (litres) | كمية الماء اليومية (لتر) |
| 2 | Daily screen time (hours) | ساعات استخدام الشاشات يومياً |
| 3 | Preferred menu style | نمط القائمة المفضّل |
| 3 | Preferred feedback style | أسلوب التغذية الراجعة المفضّل |

## Hypotheses · الفرضيات

- **H1:** Users prefer a simple numbered menu over complex forms.
  يفضّل المستخدمون قائمة مرقّمة بسيطة على النماذج المعقّدة.
- **H2:** Short motivational alerts motivate users more than detailed statistics.
  التنبيهات التحفيزية القصيرة تحفّز المستخدمين أكثر من الإحصائيات المفصّلة.

## Privacy · الخصوصية

No names or personal data are collected. Results are used only for this school project.
لا نجمع أي أسماء أو بيانات شخصية، وتُستخدم النتائج لأغراض هذا المشروع المدرسي فقط.

## Technology · التقنيات

Single `index.html` file (Arabic-first, RTL) — Tailwind CSS v4 browser build, Font Awesome, Google Fonts (IBM Plex Sans Arabic / Inter), and Formspree for collecting responses. Answers are saved as a draft on the device until submitted.
